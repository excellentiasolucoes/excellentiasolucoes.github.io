📊 Como funciona o controle de acesso
1. O usuário tenta fazer login (e-mail/senha ou Google).
2. O sistema verifica se o e-mail está na lista de autorizados.
3. Se não estiver, o acesso é negado e o usuário é desconectado.
4. Se a lista estiver vazia, qualquer conta autenticada tem acesso.
